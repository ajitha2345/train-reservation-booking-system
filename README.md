Train Reservation and Booking System

A web-based train reservation and booking management system developed using Java and Spring Boot.

Overview

This project aims to simplify train searching, seat reservations, and booking management through a web-based application.

Technologies Used

- Java
- Spring Boot
- Maven
- HTML5
- CSS3
- Thymeleaf
- MySQL

Main Features

- User registration and authentication
- Train search and schedule management
- Train reservation and booking
- Booking management
- Seat reservation
- Favorite routes
- Feedback management
- Administrative dashboard

Project Structure

train-reservation-system/
├── src/
│   └── main/
│       ├── java/

├── pom.xml
└── README.md

Installation

1. Clone the repository.
2. Configure your MySQL database.
3. Update the database connection settings.
4. Run the application using Maven.

mvn spring-boot:run

Project Purpose

Developed as an academic software development project to demonstrate web application development, database integration, and object-oriented programming concepts.
